## 📌 О проекте

Это веб-приложение создано для организации и проведения онлайн-конференций с возможностью видеозвонков, обмена сообщениями и демонстрации экрана. Проект включает в себя надежный бэкенд на FastAPI и современный фронтенд на React.

> **Статус проекта:**  Активно разрабатывается (MVP). 

## ✨ Ключевые возможности

*   **Аутентификация пользователей:**  Регистрация и вход в систему через веб-интерфейс.
*   **Видеоконференция:**  Реализация видеозвонков с использованием WebRTC.
*   **Чат в реальном времени:**  Обмен сообщениями во время конференции через WebSockets.
*   **Интуитивно понятный интерфейс:**  Удобный и современный интерфейс на React.
*   **Контейнеризация:**  Готовность к развертыванию с использованием Docker.

## 🛠️ Технологический стек

*   **Бэкенд:**
    *   **API:**  FastAPI (Python)
    *   **База данных:**  SQLite / PostgreSQL (с поддержкой Alembic для миграций)
    *   **Аутентификация:**  JWT (JSON Web Tokens)
    *   **Real-time:**  WebSockets
    *   **Видео:**  WebRTC
*   **Фронтенд:**
    *   **Библиотека:**  React (Create React App)
    *   **Языки:**  JavaScript, CSS
*   **Инфраструктура:**
    *   **Контейнеризация:**  Docker
    *   **Веб-сервер:**  Uvicorn (для бэкенда)

## 🚀 Быстрый старт

Инструкции по запуску проекта на локальной машине для целей разработки и тестирования.

### 🐍 Запуск бэкенда

1.  **Убедитесь, что у вас установлен Python 3.13.**
2.  **Перейдите в директорию backend:**
    ```bash
    cd backend
    ```
3.  **Создайте и активируйте виртуальное окружение:**
    *   Windows:
        ```bash
        python -m venv venv
        venv\Scripts\activate
        ```
    *   macOS/Linux:
        ```bash
        python3 -m venv venv
        source venv/bin/activate
        ```
4.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
5.  **Примените миграции базы данных:**
    ```bash
    alembic upgrade head
    ```
6.  **Запустите сервер разработки:**
    ```bash
    uvicorn main:app --reload
    ```
    Бэкенд будет доступен по адресу: `http://localhost:8000`

### ⚛️ Запуск фронтенда

1.  **Убедитесь, что у вас установлены Node.js и npm.**
2.  **Перейдите в директорию frontend:**
    ```bash
    cd frontend
    ```
3.  **Установите зависимости:**
    ```bash
    npm install
    ```
4.  **Запустите приложение React:**
    ```bash
    npm start
    ```
    Фронтенд будет доступен по адресу: `http://localhost:3000`

> **Примечание:**  Фронтенд настроен на взаимодействие с бэкендом по умолчанию по адресу `http://localhost:8000`. При необходимости вы можете изменить этот URL в файле `frontend/src/config.js`.

### 🐳 Запуск через Docker

Проект поддерживает запуск с помощью Docker, что упрощает развертывание.

1.  **Убедитесь, что у вас установлен Docker.**
2.  **Соберите Docker-образ для бэкенда:**
    ```bash
    cd backend
    docker build -t hackaton2025-backend .
    ```
3.  **Запустите контейнер:**
    ```bash
    docker run -p 8000:8000 hackaton2025-backend
    ```

Для запуска фронтенда в контейнере необходимо создать отдельный Dockerfile. В текущей версии фронтенд запускается локально с помощью `npm start`.

## 📱 API Эндпоинты

Бэкенд предоставляет REST API. После запуска сервера документация автоматически доступна по адресу:

*   **Swagger UI:** `http://localhost:8000/docs`
*   **ReDoc:** `http://localhost:8000/redoc`

Основные эндпоинты (планируются к реализации):

| Метод | Эндпоинт                | Описание                      |
| :---- | :---------------------- | :---------------------------- |
| POST  | `/api/register`         | Регистрация нового пользователя |
| POST  | `/api/login`            | Аутентификация и получение JWT |
| GET   | `/api/rooms`            | Получение списка доступных комнат |
| POST  | `/api/rooms/create`     | Создание новой комнаты         |
| WS    | `/ws/chat/{room_id}`    | WebSocket-соединение для чата  |
| ...   | ...                     | ...                           |
